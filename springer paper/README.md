# Springer LNCS Manuscript

This directory contains the complete research paper manuscript formatted according to Springer LNCS (Lecture Notes in Computer Science) standards.

## Files & Structure:
- `main_springer.tex`: Complete LaTeX source in Springer LNCS format (`llncs` document class, 12 pages).
- `references.bib`: Standardized BibTeX database with 27 peer-reviewed references.
- `figures/`: Vector PDF figures for publication (`fig_pipeline.pdf`, `fig_shap.pdf`, `fig_athlete_profiles.pdf`, and `figure_manifest.json`).
